# 战斗扩展 Stage3 · 使用手册

> 版本 **v1.0.0** ｜ 适用于 SillyTavern + 酒馆助手（JS-Slash-Runner）+ MVU

## 1. 它是什么 / 不是什么

### ✅ 它做什么

| 能力 | 说明 |
| --- | --- |
| **战斗搬进悬浮窗** | 点右下角悬浮球开关面板，战斗过程不占主楼正文 |
| **数据由面板自己持有** | 开机从 MVU 存档**读一次**（角色/技能/背包/装备），之后战场数据面板自己维护 |
| **逐回合推进** | 行动轴、HP、距离、状态、冷却、连击跟着回合走 |
| **可回退 / 重放** | 打错了能退回去，HP/距离/冷却/背包一起退 |
| **AI 只说话不写状态** | AI 在 `<BattleState>` 里描述战场，面板负责记账 |
| **结算写回主楼** | 战斗结束可写一条精简战报回聊天记录 |

### ❌ 它不做什么

| 不做 | 原因 |
| --- | --- |
| **不写回 MVU 变量** | 面板是「只进不出」，销毁冲突根源（详见 FAQ） |
| **不执行 AI 的 `<json_patch>`** | 同上，两个写者必然打架 |
| **不管经验/技能点分配** | 那是主楼脚本的事。面板只读来显示 |
| **不管经营 / 建设 / 资产** | 不在战斗面板职责内 |
| **不替你决定行动** | 你说了做什么，它才推演什么 |

## 2. 装之前要准备什么

| 需要 | 说明 | 怎么确认 |
| --- | --- | --- |
| **SillyTavern** | 1.12 以上（实测 1.16.0） | 能正常聊天就行 |
| **酒馆助手 / JS-Slash-Runner** | v4.9 以上 | 扩展列表里有「酒馆助手」 |
| **MVU 变量框架** | 角色卡自带（`MVU_ZOD` 脚本） | 聊天里能查看变量 |
| **角色卡有战斗相关变量** | 至少要有 `人物` 与 `技能树` | 见下方检查方法 |

### 怎么确认变量对得上

在酒馆按 F12 打开控制台，粘贴：

```js
const d = (Mvu.getMvuData({ type: 'message', message_id: 'latest' }) || {}).stat_data || {};
console.log('人物 =', !!d.人物, '｜技能树 =', !!(d.人物 && d.人物.技能树));
console.log('六维 =', d.人物 && Object.keys(d.人物.属性 || {}).join(','));
```

三行都有内容 ⇒ 可以装。

> ⚠️ 如果你的卡**没有 MVU**，面板装上了也是空的（没有可导入的数据）。

## 3. 安装步骤

### 3.1 导入脚本

1. 打开酒馆 → **酒馆助手** → **脚本库**
2. 点 **导入** → 选择 `battleExpanded3.json`
3. 导入后确认脚本出现在列表里，名字是 **`【本体】战斗扩展 Stage3（面板自持数据）`**
4. **打开它的开关**（导入后默认可能未启用）

> 🔴 **只导入这一个文件就够了。**
> 如果看到别的 `…测试数据包` 文件，那是开发测试用的，普通使用**不要装**。

### 3.2 刷新页面

导入脚本后**必须刷新一次**（F5）。按钮事件是页面加载时注册的。

### 3.3 确认装上了

刷新后看**页面右下角**：应该有一个**悬浮球**。

- 有球 ⇒ 装好了，点它打开面板
- 没球 ⇒ 见 [FAQ 9.1](#91-装了但右下角没有悬浮球)

## 4. 第一次打开：导入存档

打开面板后，**先导入存档**，否则一切都是空的。

```
面板顶栏  →  ↺ 导入存档
```

点一下，面板会从 MVU 读一次，日志里会出现：

```
已从存档导入：1 个单位、38 个技能、52 件道具、18 件装备、5 个资源技能
（之后战场数据由面板持有，不再与 MVU 互相覆盖）
```

看到这行就成功了。

> 🔴 **什么时候要重新导入？**
> 只有在**主楼那边角色数据变了**（升级、学新技能、换装备、背包变动）才需要。
> 战斗中的 HP 变化**不需要**重新导入 —— 面板自己记账。

### 导入后会看到什么

| 位置 | 内容 |
| --- | --- |
| 左栏 | 你的角色卡（六维 / 战斗属性 / 资源 / 状态） |
| 中栏【战场】 | 一块空画布（还没开战） |
| 中栏【技能栏】 | 你的技能（默认折叠，点开看） |
| 右栏【背包】 | 你的道具与装备 |
| 右栏【同伴】 | 羁绊 / 附近的人（参考名单，默认不发） |

## 5. 打一场仗（完整流程）

### 第一步：进入战斗

```
中栏【战斗条】→ 【进入战斗】
```

> ⚠️ 按钮会**发一次请求**问 AI「战场怎么布置」。这是有意的（让 AI 决定开局）。
> 已在战斗中时该按钮会**变灰禁用**。

### 第二步：在面板输入框写你的行动

在**面板中栏底部**的输入框里写你这一轮要做什么，例如：

```
$【灾厄投掷】 朝训练木人的咽喉掷出骨标
```

> 💡 点技能栏里的技能会自动往输入框插 `$【技能名】` 标记，不用手打。
> ⚠️ 注意是**面板自己的输入框**，不是酒馆聊天框。

### 第三步：点【✈ 发送】

```
面板中栏底部 → 【✈ 发送】
```

面板会把「战场现状 + 你这一轮的行动」发给 AI，AI 回复后：
- 面板解析 AI 写的 `<BattleState>`
- 更新 HP / 距离 / 状态 / 冷却
- 回合 +1

> 也可以在输入框里按 **Enter** 直接发。

### 第四步：看回合日志

```
右栏 → 【回合日志】
```

有五个页签：

| 页签 | 看什么 |
| --- | --- |
| **正文** | AI 写的叙事 |
| **数值** | 每轮的结算明细 |
| **系统** | 面板自己的操作记录 |
| **思维链** | AI 的推演过程（**排查用**：看它有没有真算） |
| **原始回复** | AI 的原文（**排查用**：判断是它没写还是面板读错） |

### 第五步：打完收工

```
中栏【战斗条】→ 【结算战场（写回主楼）】
```

会往聊天记录里写**一条** assistant 楼层（精简战报），然后清空战场数据。

> 只想看看战报、不想写回？用【结算战场（只看）】（在输入框旁边）。

### 打错了怎么办

```
中栏【战斗条】→ ◀ 上一回合    （退一轮）
中栏【战斗条】→ 下一回合 ▶    （前进一轮）
```

HP / 距离 / 技能冷却 / 连击组 / 背包 / 资源**全部一起退**。
条上的 `1/1` 会跟着变（前面是当前位置，后面是历史总数）。

## 6. 界面各块怎么用

### 悬浮球

| 操作 | 效果 |
| --- | --- |
| 点一下 | 开关面板 |
| 拖动 | 换位置（**松手才落盘**，过程中不卡） |
| 双击顶栏 | （未实现，见已知限制） |

### 顶栏按钮（只有三个）

| 按钮 | 作用 |
| --- | --- |
| **⚙** | 显示/隐藏**左栏配置**（技能系统 / 后台数据 / API / 预设 / 世界书） |
| **↺** | **导入存档**（从 MVU 读一次） |
| **✕** | 关闭面板 |

> 🔴 **注意：战斗操作按钮不在顶栏**，在下方【战斗条】。

### 战斗条（中栏，战斗中一直可见）

这一条同时是**回合指示 + 战斗操作**：

| 按钮 | 作用 |
| --- | --- |
| **进入战斗** | 开战（会发一次请求让 AI 布置战场）。已在战斗中则禁用 |
| **◀ 上一回合** | 回退一轮（HP/距离/冷却/背包一起退） |
| **下一回合 ▶** | 重放一轮 |
| **结算战场（写回主楼）** | 生成战报写进聊天记录，然后结束战斗 |
| **推进回合** | 问 AI 并推进一轮 |
| **清空面板** | 清掉战场数据（**慎用**，会丢当前战斗） |

条上还显示：`⚡ 本回合使用 N`、`条件 战斗中/未在战斗中`、`回合 #N`、`回退进度 1/1`。

### 发言输入框（中栏底部）

```
[ 输入你的行动…（Enter 发送 / Shift+Enter 换行） ]  [✈ 发送] [结算战场（只看）]
```

- **Enter 发送**，**Shift+Enter 换行**
- 旁边的 **【结算战场（只看）】** 只生成摘要、不写回主楼、不结束战斗

### 中栏

| 卡 | 内容 |
| --- | --- |
| **【当前目标】** | 你现在盯着谁（点它切换） |
| **【战场】** | 俯视 SVG 画布：单位位置、距离、布景。可缩放 / 拖动 |
| **【小队】** | 你 + 队友的头像卡（HP / SAN） |
| **【回合日志】** | 见上一节 |

### 右栏

| 卡 | 内容 |
| --- | --- |
| **【目标状态栏】** | 当前目标的全套数据（点顶部条切目标） |
| **【技能栏】** | 技能格（点击插入标记，再点取消） |
| **【背包】** | 道具网格，支持框选、丢弃、移库（**只改面板**） |
| **【同伴 / 附近的人】** | 参考名单，勾选决定哪些资料发给 AI |

### 画布操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 | 缩放 |
| 拖动空白处 | 平移 |
| 点单位 | 选中 / 看距离 |
| 点两个单位 | 显示这两人的距离 |
| 点布景对象 | 看详情 |

## 7. 技能系统：经典 vs 组合

面板支持两套，在**左栏【⚡ 技能系统】**里切。

### 经典模式

```
主动技能槽 7 格（森精种 8 格）+ 觉醒 2 格（森精种 3 格）
```

- **没有**「基础 / 转职 / 高级组 / 终式」的区分
- 你在 `主动技能槽` 里装了哪 7 个，面板就显示哪 7 个
- 适合起步期：技能选择自由

### 组合模式

```
基础 3 格 + 转职 3 格 + 高级/终式 3 格 = 9 格
```

- 有连击：两两配对决定切到哪个高级组（1+2→I，3+4→II，5+6→III）
- 终式：当前组同回合用掉 ≥2 个技能、且终式有可用技能时切进终式
- 适合成型期：连击倍率更高

> 🔴 **切模式会清空 `主动技能槽`**（主楼脚本的既定行为）。
> 切到经典模式后看到一排空格是**正常的**，重新选满 7 个即可。

## 8. 配 AI 通道（独立 API）

面板默认走**酒馆自己的模型**。也可以配独立 API（不消耗酒馆的正文额度）。

```
顶栏 ⚙  →  左栏展开  →  找到【API】小节
```

左栏共有五节：**技能系统 / 后台数据 / API / 预设 / 世界书**。

| 字段 | 说明 |
| --- | --- |
| **名称** | 随便起，只给你自己看 |
| **地址** | 例如 `https://api.openai.com/v1`（**带 `/v1`，不带 `/chat/completions`**） |
| **模型** | 例如 `gpt-4o`。点【查模型】自动拉候选列表，也可以自己填 |
| **密钥** | 你的 API Key |

点【**测试连接**】确认通，再点【**应用**】。

### 密钥存在哪

存在**酒馆的脚本变量**里（`battleExpanded3`），不进聊天记录、不进产物文件、**不回显到页面**。

> ⚠️ 但它**不是加密**的 —— 任何人能打开你这台机器的酒馆就能看到。共用电脑请注意。

### 没配 API 怎么办

不影响。面板会走酒馆当前模型（`generateRaw`），只是速度/质量取决于你酒馆的配置。

## 9. 常见问题

### 9.1 装了但右下角没有悬浮球

按顺序排查：

1. **刷新过页面了吗？** 导入脚本后必须 F5
2. **脚本开关打开了吗？** 酒馆助手 → 脚本库 → 找到它 → 开关
3. **看控制台报错**：F12 → Console，搜 `battle-expanded-stage3`
4. 报 `xxx is not defined` ⇒ 可能装成了「测试数据包」而不是本体

### 9.2 导入存档后是空的

```js
// 控制台确认变量结构
const d = (Mvu.getMvuData({ type: 'message', message_id: 'latest' }) || {}).stat_data || {};
console.log(Object.keys(d));
```

- 没有 `人物` ⇒ 你的卡不是这套变量结构，面板用不了
- 有 `人物` 但没 `技能树` ⇒ 技能栏会是空的（其余功能正常）

### 9.3 面板不打字 / 点了发送没反应

看顶栏有没有「生成中…」。按分类处理：

| 顶栏提示 | 原因 | 怎么办 |
| --- | --- | --- |
| **上次生成失败（HTTP）** | API 地址或密钥错 | 检查配置页，点【测试连接】 |
| **上次生成失败（上游）** | 模型报错 / 额度用尽 | 换模型，或查 API 后台 |
| **上次生成失败（网络）** | 断网 / 跨域 | 检查网络；本地 API 要允许跨域 |
| **上次生成失败（无宿主）** | 不在酒馆环境 | 确认在 SillyTavern 页面里 |

### 9.4 掉 HP 面板变了，但掉 SAN 没变

**先确认 AI 把 SAN 写在哪。**

面板只解析 `<BattleState>`。如果 AI 只把 SAN 写进了 `<CombatSnapshot>`，
面板读不到（这是两个不同的块）。

**怎么判断**：打开【回合日志 → 原始回复】，找 `<BattleState>` 里的单位行：

```
✅ 正确： [自身] 拉缇娜 | HP 29/30 | SAN 48/49 | 距离 0
❌ 读不到：[自身] 拉缇娜 | HP 29/30 | 距离 0        ← 没有 SAN
```

如果 AI 一直写错位置，可以在**你的世界书或预设**里加一句强调：
「SAN 必须写进 `<BattleState>` 的单位行」。

### 9.5 HP 数字对不上主楼

面板的 HP 来自 **AI 在 `<BattleState>` 里的声明**，不是主楼变量。
两边不一致说明 AI 写的和主楼改的不是一个数。

**以谁为准？** 战斗期间以**面板**为准（它按回合记账）；
战斗结束后点【结算战场（写回主楼）】，主楼拿到面板的结果。

### 9.6 技能栏少了几个技能

| 现象 | 原因 |
| --- | --- |
| 经典模式只显示 3 格 | 只装了 3 个主动技能 → 其余 4 格是空的（**正常**） |
| 切模式后全空 | 主楼脚本切换时清空了槽位（**正常**，重新选） |
| 组合模式只有 6 格 | 高级组没配（高级组需要「进阶/必杀」阶位技能） |
| 觉醒技能不显示 | 觉醒槽没装，或技能没学会（等级 0） |

### 9.7 面板一直不推进回合

AI 每轮都写「本轮未行动: 某某」+ 同一句理由，面板会**停在原地**。

现象：你自己觉得打了好几回合，但面板轮次不变。

**怎么办**：打开【回合日志 → 思维链】，看 AI 是不是在偷懒（没把敌方回合演完）。
面板有**连续停留上限 2 轮**的保护，超过会自动推进。

### 9.8 回退之后数字乱

先确认是不是**回退前改过主楼变量**。回退只回面板自己的历史，
**不会**把主楼变量也退回去（面板不写主楼，所以退不了）。

如果数字确实乱，最干净的办法：**重新导入存档**（回到基线）。

## 10. 已知限制

| 限制 | 说明 |
| --- | --- |
| **不写回 MVU** | 面板改的背包/装备/HP 都不进存档，要写回得走【结算战场】 |
| **背包/装备只在面板改** | 丢弃、移库、穿脱都只影响面板显示 |
| **经验/技能点只读** | 分配技能等级请在主楼做 |
| **双击顶栏最大化** | 未实现 |
| **吸边** | 未实现 |
| **结算预览不显示在界面** | 只进日志（【回合日志 → 正文】）和 `__BE3__.settleText()` |
| **主楼自己 RP 的回复面板收不到** | 只有面板发的请求才会被解析 |
| **真机大样本未长期验证** | v1.0.0 是首个正式版，遇到问题请带【原始回复】反馈 |

## 11. 卸载与还原

### 停用（保留数据）

酒馆助手 → 脚本库 → 关掉开关 → 刷新页面。悬浮球会一起消失。

### 完全删除

1. 脚本库 → 删掉 `【本体】战斗扩展 Stage3`
2. 可选：清掉它存的配置（API / 面板选项）

```js
// 控制台执行 —— 清掉面板存的脚本变量
const all = getVariables({ type: 'script' }) || {};
delete all.battleExpanded3;
replaceVariables(all, { type: 'script' });
console.log('已清除 battleExpanded3 脚本变量');
```

### 会不会影响主楼

**不会。** 面板不写 MVU、不改预设、不动世界书。
唯一的「写入」是你主动点【结算战场（写回主楼）】时，往聊天记录加一条消息。

## 附录 A：面板内部调试入口

高级用户 / 排查用。控制台执行（`__BE3__` 是面板挂出来的调试对象）：

```js
__BE3__.snapshot()      // 当前战场表（谁在场上、HP、距离、状态）
__BE3__.log()           // 面板日志（★ 不是 logs）
__BE3__.rounds()        // 回合历史
__BE3__.settleText()    // 结算预览文本（界面上不显示，只能从这里看）
__BE3__.advance()       // 快进 1 轮（不调 AI）
__BE3__.advanceN(3)     // 快进 3 轮（不调 AI）
__BE3__.undo()          // 回退一轮
__BE3__.redo()          // 重放一轮
__BE3__.bag()           // 背包切片
__BE3__.equipment()     // 装备切片
__BE3__.resources()     // 资源技能
__BE3__.canvas()        // 画布视口
__BE3__.send('文字')    // 直接发一句（走完整发送链路，不经聊天框）
__BE3__.feed('AI原文')  // 直接喂一段 AI 回复并解析（排查解析问题最好用）
__BE3__.version         // 版本号
```

> 💡 **`feed()` 是最好用的排查入口**：把你从【原始回复】复制的 AI 原文丢进去，
> 立刻能看到面板解析出了什么。不经过网络、不消耗 API。
